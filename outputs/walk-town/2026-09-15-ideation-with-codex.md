# さんぽタウン アイデア出し(Claude × Codex)

2026-09-15。[MVP計画書](../../plans/2026-09-15-walk-town-app-mvp.md)の世界観と楽しさの仕掛けを、ClaudeとCodexで出し合った記録。判断基準は、MVPで確かめたい3つ(言われなくても開くか、並べ替えるか、人に見せたくなるか)に効くかと、作る量に見合うか。

## 世界観

| 案 | 出した側 | 判定 | ひとこと |
|---|---|---|---|
| 湖畔のよりみち | Codex | 推奨 | 湖を盤面の外の背景にでき、12種でも統一感が出る。滋賀とつながる |
| 海辺の小さな町 | Claude | 採用候補 | 灯台を中心に見栄えのする構図を作りやすい |
| 昭和レトロ商店街 | Claude | 採用候補 | 店の並びで生活感が変わる。看板の描き込みは手間 |
| 空に浮かぶ島 | Claude | 採用候補 | 6×6の小ささが魅力になる |
| お菓子缶のなかの町 | Codex | 採用候補 | 缶の縁が額縁になり、小物が少ない初日から作品に見える |
| 夜の町 | Claude | 条件付き | 常に夜なら軽いが、昼夜両方の絵は作る量が倍 |
| 野球場のある町 | Claude | 条件付き | テスターの野球への関心が不明 |
| 坂の途中の休憩所、雨上がりの路地 | Codex | 候補 | 背景で雰囲気を出す案 |

## 仕掛け

| 案 | 判定 | MVPでの扱い |
|---|---|---|
| 隣に置くと小さな出来事が起きる | 推奨 | 2組だけ。絵が重なるだけで、時間待ちや動きはなし |
| 絵はがきモード | 推奨 | ボタンで操作表示を隠し、枠を出してスクショしやすくする |
| 同じ物を並べると並木や庭になる | 追加ルールなしで自然に成立 | 仕様の追加は不要 |
| 街に名前をつける | 軽い | 候補。絵はがきに表示できる |
| 時刻で明かりがつく | 条件付き | 夜の絵が必要なので見送り |
| 実際の天気と連動 | 却下 | 通信が必要で、サーバーなしの方針に反する |
| 包みに歩数と日付を刻印 | 簡略化して候補 | 「受け取った日と歩数便」程度に |
| 包みの色が時間帯で変わる | 候補 | 開封の期待は測れるが、街への愛着には効きにくい |
| 住人が散歩する | 却下 | 動きの調整が重い |
| 週刊の町の新聞 | 却下 | 2週間では2回しか試せない |

## 名前候補

さんぽタウン、てくてくまち、おさんぽ箱庭、ポケットタウン(Claude)、よりみち便、てのひら日和、あるいて、こまち、ちいさな帰り道(Codex)。どれも既存アプリや商標との重複は未確認。

## 小物12種の案(湖畔のよりみち)

- ふつう(8): 木のベンチ、丸い広葉樹、ヨシの植え込み、小さな花壇、丸灯の街灯、赤い郵便ポスト、かご付き自転車、木製の案内板
- すこし珍しい(3): 湖畔の喫茶スタンド、ソフトクリームの売店、手こぎボートの展示台
- 珍しい(1): 小さな時計塔

出来事:
- ベンチの隣に広葉樹 → ベンチで猫が昼寝する
- 喫茶スタンドの隣に自転車 → かごに持ち帰りの紙袋が入る

猫と紙袋は演出用の絵で、小物12種には数えない。
