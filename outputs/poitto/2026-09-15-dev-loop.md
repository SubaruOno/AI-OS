# Poitto 開発ループ記録 (2026-09-15 21:50〜)

すばるの依頼で、Claude と Codex が約1時間「仮説 → 実装 → 検証 → 考察」を回した記録。Codex が実装、Claude がシミュレータでビルド・画面撮影・コミットを担当。UI の雰囲気は本人未回答のため「紙・文房具の手触り」を仮説として採用。

## サイクル1 (21:50〜22:10)

- 仮説: 紙・文房具風の UI と、ステージ解放・最高★の保存があれば、世界観が伝わり続けて遊ぶ動機になる。
- 実装: 方眼紙背景のタイトル、カード型ステージ選択、UserDefaults の進行保存(★0でも次を解放)、リザルトから「次のステージへ / もう一度 / ステージ選択」、画面直行の起動フラグ `-screen`。
- 検証: シミュレータでビルド成功。タイトル・ステージ選択・クリア画面を撮影。
- 考察:
  - 良い点: 紙の世界観が統一されていて、アプリとして整って見える。文言も柔らかい。
  - 足りない点: タイトルが一般的なアプリのトップに見え、「部屋で紙屑を飛ばすゲーム」だと伝わらない。3D の部屋が一切映っていない。
  - ステージが2つしかなく、2つ目は練習用の直線コースで「進む楽しさ」がない。
  - リザルトのカードが画面を覆い、クリアした瞬間の部屋が見えない。

## サイクル2 (21:58〜22:05)

- 仮説: タイトル背景に実際の3D部屋を映し、ステージを5つにすれば、ゲームらしさと進みたい気持ちが出る。Codex は賛成。
- 実装: 本棚・カーブ・遠距離の3面を追加し、直線コースは5面目のおまけに。タイトルは3D部屋の静止背景と半透明パネル。リザルトはプレイ画面を残してカードを下半分へ。`-screen play -stage N`。選んだステージが描画・判定に渡っていなかった不具合も Codex が修正。
- 検証: ビルド成功。タイトル、クリア画面、ステージ2と4の開始画面を撮影。
- 考察:
  - 良い点: タイトルで部屋とリングが見え、ゲームだと伝わる。クリア画面でゴミ箱が見えて達成感が出た。
  - 足りない点: タイトルの構図が机の角を切り取っていて雑然。カードがロゴの見せ場を奪っている。
  - プレイ画面に開発用表示「fps / dof off / rolling」が出たまま。
  - ステージ2と4の開始画面がほぼ同じ見た目で、違いは奥にしかない。ステージ名もプレイ中に出ていない。
  - 新ステージが実際にクリアできるかは未検証。

## サイクル3 (22:05〜22:08)

- 仮説: 開発用表示を消し、ステージ名を出し、ステージごとに見た目の個性を持たせ、クリアできることを自動テストで保証すれば、完成品らしさと各ステージの印象が上がる。
- 実装: 開発用表示は `-debug-hud` のときだけ。上部の紙ラベル(STAGE 04 高い棚から、遠くまで)、左上の戻るボタン、開始時の名前カード。5面の机素材・色・照明を変えた。タイトルは机の上から奥を見る構図に、ロゴを上部に大きく。実際の120Hz更新で入力を探索し、クリアできる入力列を探すテストを追加。
- 検証: テスト11件中、ステージ「本棚」だけクリアできる入力列が見つからず失敗。他4面はクリア可能を確認。タイトルとステージ4を撮影。
- 考察:
  - 良い点: タイトルが「このコースを飛ぶゲーム」だと一目で分かる構図になった。ステージ4は夜の青い部屋と濃い机で、1面と明確に違う。ラベルでどこを遊んでいるか分かる。
  - 足りない点: 本棚ステージがクリア不能、または探索が浅い。ロゴの背後が暗い壁で読みにくい。名前カードは撮影が早すぎて未確認。

## サイクル4 (22:08〜22:12)

- 仮説: 本棚ステージのクリア不能は、配置が厳しすぎるか探索が浅いことが原因。切り分けて直し、全ステージをテストで保証すれば、実機のプレイテストに安心して出せる。
- 原因: 探索範囲の不足。機首下げ入力を −1 まで広げると、配置を変えずに解が見つかった。−1 はプレイヤーの実際の入力範囲内(`SpikeWorld` で −1〜1 に制限)であることを Claude が確認。
- 実装: 全探索の成功件数を出すテストと難易度順のチェック。ステージ3はゴミ箱と最後のリングを左へ1m移動して難易度の逆転を解消。ロゴの背後にぼかした紙色。ProgressTests をテスト形式を揃えて実行対象に。
- 検証: テスト全件成功(クリア可能性・飛行・進行保存)。入力10,496通りのうち成功は、ステージ1から順に 15.3% / 14.8% / 14.1% / 9.6%。ステージ1〜4で難しくなっている。ただし機械の総当たりの数字で、人の成功率ではない。
- 考察:
  - 良い点: 全ステージがクリア可能と保証された。ロゴが読める。ステージ3は緑の部屋、名前カードも見やすい。
  - 足りない点: ステージ1〜3の難易度差が小さい(15.3→14.1%)。ステージ選択が縦に長い文字だけのリストで、進んでいく楽しさがまだ弱い。
