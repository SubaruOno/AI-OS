# Poitto 家ステージ開発ループ記録 (2026-09-16〜)

[ステージ企画](2026-09-16-house-stage-ideas.md)のうち、子ども部屋 → 廊下 → 階段 の3面を Claude と Codex で作る記録。縮尺は今の「紙屑から見た巨大な家」のまま(すばるは縮尺の質問に明示回答なし、手直しの少ない方を Claude が選択)。

## 準備

- Poly Haven から CC0 の家具モデル8点(勉強机、木の椅子、棚、ベッド、百科事典セット、目覚まし時計、コンソールテーブル、オットマン)の USD 1k 版を `~/Projects/Poitto/ArtSource/polyhaven/` にダウンロード。合計21MB。すばるの許可済み。

## H1

- 依頼: モデルを USDZ に変換、家具ごとの判定箱、往復するロボット掃除機、新3面、判定箱の表示フラグ、難易度目標 5〜8% / 3〜6% / 2〜4%。旧5面は `-legacy-stages` に退避。
- 結果: Codex は配置データ(`HouseStages.swift`)、家具ごとの判定箱、動く障害物の判定、モデル変換まで進めたところで利用上限に達した(次回は 9/20 15:18)。以降は Claude が引き継いだ。

## H1 の続き (Claude)

- 実装: 家具モデルの読み込みと配置、判定箱をそのまま描く代替表示、`-debug-hitboxes`、ロボット掃除機の見た目、全体を見下ろす撮影用 `-overview`。家ステージ用のクリア可能性テスト(リングを経由してゴミ箱へ向かう操作で、1回目のジャンプ時刻・着地後の再ジャンプ・機首の角度を総当たり)。旧5面のテストは `legacy` に向け直し、進行保存のテストを新3面に合わせて書き換えた。
- 検証で分かったこと:
  - 階段の最初の案(踊り場で180度折り返す)は、クリアできる操作が1つもなかった。紙飛行機の旋回半径より踊り場が狭く、端から転がり落ちるか、飛びすぎて壁に当たる。まっすぐ降りて踊り場に一度着地し、天井の梁の下を抜けて吹き抜けから下の階へ飛ぶ形に作り直した。
  - 難易度の順番をそろえるため、廊下の掃除機を少し大きく速く、子ども部屋のゴミ箱の入口を少し広くした。
- テスト: 全件成功。操作3,528通りでの成功率は 子ども部屋 2.04% / 廊下 1.84% / 階段 0.51%。旧5面(15〜8%)よりはっきり厳しい。人の難しさとは別物。
- 見た目: 子ども部屋はベッド・勉強机・椅子・棚・本・時計が並び、部屋らしくなった。廊下と階段はまだほとんど箱で、上からの撮影も高い壁に隠れてしまう。モデルの読み込みに数秒以上かかる。
- 実機: ビルド・インストール成功。

## 次の課題

- モデル読み込みの待ち時間(非同期化かファイルの軽量化)
