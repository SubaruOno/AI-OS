# tidy-inbox — ダウンロードとデスクトップを空に保つ

`~/Downloads` と `~/Desktop` は一時置き場で、ファイルの住所ではありません。
この決まりは [CLAUDE.md](../CLAUDE.md) の「Downloads and Desktop stay empty」にあります。
この道具は、2つのフォルダから「確実に要らないもの」を見つけてゴミ箱に入れ、
残りを本来の場所へ移すときの記録を残します。

場所は [scripts/tidy_inbox.py](../scripts/tidy_inbox.py)。Python 3 の標準ライブラリだけで動きます。

## ゴミ箱に入れる基準

次のどれかに当てはまるものだけを、`/usr/bin/trash` でゴミ箱に入れます。
ゴミ箱を空にするまでは、Finderの「戻す」で元に戻せます。

- 中身がまったく同じファイルが、ホーム直下のテーマ別フォルダ（`~/野球`、`~/大阪ガス`、`~/大学` など）にすでにある
- フォルダの中のファイルが、すべてテーマ別フォルダにすでにある
- zipの中身が、すべてテーマ別フォルダにすでにある
- インストール済みアプリのインストーラ（`.dmg`、`.pkg`）
- Officeの一時ファイル（`~$` で始まる）、途中で止まったダウンロード、クラッシュログ
- 空のフォルダ

同じかどうかはファイル名ではなく中身で判定します（SHA-1、zipはCRC）。
24時間以内に変更されたものは、使っている途中かもしれないので触りません。

## 使い方

```bash
python3 scripts/tidy_inbox.py scan --json /tmp/tidy.json
python3 scripts/tidy_inbox.py trash --json /tmp/tidy.json
python3 scripts/tidy_inbox.py move "~/Downloads/<ファイル>" "~/野球/<フォルダ>"
```

`scan` は判定の一覧を出すだけで、何も動かしません。判定が `sort` のものは
基準では決められないので、ファイル名と [CLAUDE.md](../CLAUDE.md) の置き場所の表を見て、
`move` で移すか、そのまま残します。`move` は移動先に同じ名前があると
「名前 (2)」のように番号を付けます。

ゴミ箱に入れたものと移したものは、[tidy-inbox-log.tsv](../private/tidy-inbox-log.tsv) に日時つきで残ります。
元に戻すときはこの記録を見ます。

## 毎週の自動実行

Claudeアプリの予定タスク「ダウンロードとデスクトップの片付け」が、毎週日曜21時に動きます。
アプリが閉じていた場合は、次に開いたときに動きます。
1回の流れは、`scan` → `trash` → 行き先がはっきりしたものだけ `move` → 迷ったものの一覧を報告、です。
本人確認書類や鍵のファイルは中身を開かずに `~/Documents/重要書類/` へ移します。
