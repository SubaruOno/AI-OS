# 投球カット（pitch-cut）

ネット裏から撮りっぱなしの試合動画を、投球の場面だけにつないだ動画にする道具。BASSに1球ずつ入力するとき、投球と投球の間の待ち時間を早送りしなくて済むようにする。コードは [pitch_cut.py](../apps/pitch-cut/pitch_cut.py)。

## 使い方

```bash
python3 apps/pitch-cut/pitch_cut.py "~/Downloads/試合.mp4"
```

元の動画の隣に `<元の名前>_投球カット.mp4` ができる。`--out` で置き場所を変えられる。`--no-voice` を付けると、記録係の声（打者紹介・交代）の場面を足さない。

かかる時間の目安（3時間20分の動画）: 人物検出が約18分、文字起こしが約15分、書き出しが数分。途中の結果は `~/.cache/pitch-cut/<動画名>/` に残るので、2回目からは書き出しだけになる。

## 切り方

手本は、すでにカットされて届く映像（台湾U23の日本遠征の動画、日本通運の8/23西濃運輸戦）。どれも1球あたり約8秒で、次のように切ってある。

- 始まり: 捕手と球審がしゃがみ、投手が動き出すころ（球審が立つ3〜6秒前）
- 終わり: 捕手が捕って球審が立ってから3秒ほど
- 打球が飛んだ球: カメラが打球を追い終わるまで
- 落とすもの: 投球と投球の間、イニング間の投球練習、攻守交代

道具の中では、人物検出（YOLO）の枠が横長になる時間を「球審と捕手がしゃがんでいる時間」とみなし、しゃがみの終わりを投球としている。しゃがんでいても打者がいない時間（投球練習）は外す。記録係の声は whisper で文字にし、「〇番」「代わり」「攻撃」などを含む行だけ数秒残す。

## 確かめたこと（2026-10-15 日本通運ー新日鐵住金鹿島、3時間20分）

- 21分台の5球を目で確かめ、5球とも拾えていた。イニング間の投球練習は外れていた。
- 拾った投球の候補から無作為に24件を見ると、約8割が本物の投球。残りは打者が構え直す間などで、1件あたり数秒余分に残るだけ。
- 切り落とした側で強い音がした場面を12か所見たが、取りこぼした投球は見つからなかった。
- 試合終盤に、しゃがみが長く続いて2球が1つにまとまり、前の球が落ちていたことがあった。しゃがみの始めから残す形に直した。
- 全部の球を確かめたわけではない。取りこぼしに気づいたら、元の動画のその時刻を見る。区切りの一覧は `~/.cache/pitch-cut/<動画名>/区切り.json`（元の動画の秒）。

## 前提

- 人物検出の重み `~/野球/batting_analysis/yolo11n.pt`、whisper のモデル `~/.cache/whisper/ggml-large-v3-turbo.bin`、`ffmpeg`、`whisper-cli`
- カメラはネット裏の1台で、球審・捕手・打者が画面の中央付近に映っていること。外野や一塁側からの映像は想定していない。
- 文字起こしの時刻は粗く、声の場面は数秒ずれることがある。
