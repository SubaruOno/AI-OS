# Start here

You can use this kit with **Claude Code or Codex**, on **Windows or macOS**.
No coding experience is required.

1. Extract the downloaded zip. Do not work inside the zip preview.
2. Open the extracted folder in either:
   - **Claude Code** in the Claude desktop app, or
   - **Codex** in the ChatGPT desktop app.
3. Send this message:

> Set up this AI OS for me.

The assistant will ask whether the workspace is for you or for a business, then
guide you one question at a time. The core setup usually takes 45 to 60 minutes.
Optional accounts, connectors, and live demonstrations can take longer. You can
stop at any point and later say, “Continue my setup.”

For download links and separate Windows/macOS instructions, read
[`INSTALL-GUIDE.md`](INSTALL-GUIDE.md).

# ここから始めてください

このキットは **Claude Code と Codex** の両方で、**Windows と macOS** の
どちらでも使えます。プログラミングの知識は必要ありません。

1. ダウンロードした zip を展開します。zip のプレビュー画面の中では作業しないでください。
2. 展開したフォルダを、次のどちらかで開きます。
   - Claude デスクトップアプリ内の **Claude Code**
   - ChatGPT デスクトップアプリ内の **Codex**
3. 次のメッセージを送ります。

> このAI OSをセットアップしてください。

AI が、個人用か事業用かを最初に確認し、その後は一問ずつ案内します。
基本設定の目安は45〜60分です。外部サービスの接続や動作確認まで行う場合は、
さらに時間がかかることがあります。途中で止めても、あとで「設定の続きをして」と
伝えれば再開できます。

アプリの入手先と Windows・macOS 別の詳しい手順は、
[`INSTALL-GUIDE.md`](INSTALL-GUIDE.md) をご覧ください。
