# short-form

Turning one piece of work into a feed. Filled 2026-08-03 from Table 02, Operator Day.

**Albert Olgaard** — his actual production workspace, not a sample: `Short Form Content/` carries seven skills (`reel-editor`, `ig-carousel`, `slideshow`, `youtube-clipper`, `youtube-broll-maker`, `youtube-thumbnail-maker`, `youtube-popup-graphic`), its own CLAUDE.md, and a worked example reel with source files intact. This is 131MB of the kit's 136MB, almost all of it fonts, background music and rendered frames.

`installable-bundles/` holds `reel-editor.skill` and `youtube-popup-graphic.skill` — the same two skills packaged for one-click install in the Claude Desktop app. They were delivered separately and differ slightly from the folder versions: the trigger wording is generic and the background music track is stripped to keep the download small. Kept because they are the easier install path, not because they are better.

Read `START-HERE.md` first: it is addressed to Claude, not to you.

Nothing here is installed. Review `../COMPATIBILITY.md` first. Put an adapted skill in `.claude/skills/`, then run `python scripts/sync_harness_skills.py` from the workspace root so Claude and Codex receive the same copy.
