# Write Handoff

## Workflow

1. State the objective and current status.
2. List completed outcomes with exact artifact locations.
3. Record verification evidence.
4. Record important decisions and reasons.
5. List unresolved issues, risks, and assumptions.
6. Give the next action in executable form.
7. Exclude transient detail that does not help continuation.

## Output

Objective, completed work, artifacts, verification, decisions, open issues, and next action.

Never claim completion when the handoff describes unfinished work.
