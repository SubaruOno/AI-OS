# Review Output

## Workflow

1. Reconstruct requirements from the request and canonical sources.
2. Inspect the complete deliverable in its final form.
3. Test correctness, completeness, consistency, usability, and safety.
4. Record findings with exact evidence and locations.
5. Rank findings as blocker, important, or minor.
6. Distinguish defects from optional polish.
7. Do not modify the deliverable unless the user asks for fixes.

If no actionable issue exists, say so plainly and describe what was checked.
