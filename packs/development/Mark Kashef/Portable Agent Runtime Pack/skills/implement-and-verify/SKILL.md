# Implement and Verify

## Workflow

1. Run preflight.
2. Inspect the target, instructions, conventions, and current changes.
3. State the definition of done.
4. Implement the smallest complete change.
5. Preserve unrelated work and avoid speculative features.
6. Run the most relevant automated checks.
7. Inspect the user-facing result.
8. Review the final diff or changed artifacts.
9. Run postflight.

Lead the handoff with the outcome. Include verification, artifact locations, and remaining limitations.
