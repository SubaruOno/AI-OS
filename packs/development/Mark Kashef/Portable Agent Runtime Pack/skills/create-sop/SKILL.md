# Create SOP

## Workflow

1. Observe or reconstruct how the work is actually performed.
2. Define trigger, owner, inputs, output, and done condition.
3. Separate deterministic steps from judgment points.
4. Put steps in dependency order.
5. Add checks where failures can be prevented.
6. Define exceptions, escalation, and recovery.
7. Test the SOP on one realistic example.

## Required sections

Purpose, trigger, inputs, steps, judgment points, quality checks, exceptions, escalation, and definition of done.

Write for execution, not policy theater.
