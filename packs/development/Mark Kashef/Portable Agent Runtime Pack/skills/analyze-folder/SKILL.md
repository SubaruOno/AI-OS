# Analyze Folder

Map the project without modifying it.

## Workflow

1. Read `identity.md` and the active adapter when present.
2. Locate entry points, manifests, instructions, tests, and recent changes.
3. Read only the files required to understand purpose, architecture, and state.
4. Identify purpose, flow, canonical sources, dependencies, risks, and contradictions.
5. Separate observed facts from inference.
6. Return a concise map, the three things that matter most, unknowns, and the smallest useful next action.

Do not implement changes unless the user also asks for them.
