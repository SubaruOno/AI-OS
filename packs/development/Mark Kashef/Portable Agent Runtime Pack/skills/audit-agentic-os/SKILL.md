# Audit Agentic OS

## Workflow

1. Read the stated goal and `identity.md`.
2. Inspect the actual folder. Do not trust status claims without evidence.
3. Score each layer as missing, started, solid, or compounding.
4. Check that adapters point to one identity, rules govern workflows, agents compose existing skills, permissions match tool needs, and outcomes write back to the substrate.
5. Check staleness from the outside in: Tools, Agents, Skills, Rules, Substrate, Identity.
6. Recommend the three highest-leverage actions tied to the stated goal and exact files.

Return a six-layer scorecard, coherence findings, staleness risks, and three prioritized actions.
