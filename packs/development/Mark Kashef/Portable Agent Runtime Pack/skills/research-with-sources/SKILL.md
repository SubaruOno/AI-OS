# Research With Sources

## Workflow

1. Frame the question and the decision it supports.
2. Identify claims that require external evidence.
3. Prefer primary sources, official documentation, standards, datasets, and original research.
4. Check dates and distinguish publication date from event date.
5. Compare sources when a claim is uncertain or contested.
6. Label inference and unresolved uncertainty.
7. Cite non-trivial external claims close to their support.
8. End with the answer and implications, not a source inventory.

Never fabricate a citation or cite a search-results page as evidence.
