# Plan Work

## Workflow

1. State the required outcome in one sentence.
2. Inspect the current state.
3. Define in-scope and out-of-scope work.
4. Identify decisions, dependencies, owners, and risks.
5. Break work into outcome-based steps.
6. Order dependencies and mark safe parallel work.
7. Define evidence of completion for each material step.
8. Surface only questions that materially change the plan.

## Output

Return the outcome, assumptions, ordered steps, risks, safeguards, verification, and definition of done. Keep the plan no longer than the work requires.
