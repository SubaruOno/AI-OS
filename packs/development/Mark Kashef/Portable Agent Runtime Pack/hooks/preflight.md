# Preflight

Before consequential work, confirm:

- Goal: What outcome is required?
- Target: Which exact files, systems, or people are in scope?
- Authority: Is the requested action authorized?
- Context: Which identity, rules, evidence, and decisions apply?
- Risk: What could be exposed, overwritten, published, or made difficult to reverse?
- Workflow: Does an existing skill fit?
- Done: What evidence will prove completion?

If any answer materially changes the work and cannot be discovered safely, stop and ask.
