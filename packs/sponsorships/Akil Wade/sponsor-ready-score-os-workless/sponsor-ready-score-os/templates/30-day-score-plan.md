# 30-Day Score Improvement Plan

## Week 1: Clarity

Goal: make the user easy to understand.

Actions:

- Write one-sentence positioning
- Define exact audience
- Define sponsor categories
- Choose one sponsor outcome to sell first
- Clean public bio/profile/website headline

## Week 2: Proof

Goal: make the user easier to trust.

Actions:

- Gather best screenshots, photos, testimonials, clips, or case studies
- Create a proof page or short recap document
- Create one visual proof asset
- Write one short case study

## Week 3: Sponsor Offer

Goal: create an offer sponsors can buy.

Actions:

- Build 3 sponsor packages
- Create an activation menu
- Create one custom activation for 5 target sponsors
- Define pricing and what is not included

## Week 4: Outreach System

Goal: start sponsor conversations without chaos.

Actions:

- Build target list of 30 sponsors
- Score each sponsor
- Draft custom outreach for top 10
- Set follow-up dates
- Track replies and next steps
- Prepare a simple sponsor call script
