# 大阪ガス 対策資料

> 大阪ガス硬式野球部のアナリスト作業を、このワークスペースのセッションから行うための
> 手順書。Claude Code では `/osakagas` からも呼べる。

## 1. 置き場の決まり

材料も生成物も `~/大阪ガス` に置く。このリポジトリには入れない。選手データと試合映像は
チーム内部のものなので、`git add` の対象に入った時点で間違い。作業中に一時ファイルが
必要なら `~/大阪ガス` の中か scratchpad に置く。

すばるに見てもらう画像は、憲法どおり `~/Pictures/ai/` に置いて絶対パスを伝える。

## 2. 始める前に読むもの

作業に入る前に、必ず次の2枚を読む。ここが手順と履歴の正本で、このファイルは入口にすぎない。

- `~/大阪ガス/CLAUDE.md` … フォルダの決まり、野手・投手それぞれの作り方、既知の癖
- `~/大阪ガス/作成履歴.md` … どのチームをいつどこまで作ったか、残っている課題

投手対策の分析やコメントを書く回は、加えて次も読む。

- `~/大阪ガス/アナリストエージェント資料/system_prompt.txt` … 文体と構成のルール
- `~/大阪ガス/アナリストエージェント資料/抽出テキスト/全資料コーパス.txt` … 過去の完成資料17本

読み終えたら、履歴から分かる現状を一言で伝えてから作業に入る。

## 3. 文体

対策資料そのものの文章は `system_prompt.txt` に従う。箇条書きは「・」、打者への
アドバイスは「→」、敬語は使わない。すばるへの説明は です・ます調 のまま。

## 4. 終わったら

- `~/大阪ガス/作成履歴.md` に1行足す（`- YYYY-MM-DD · <チーム名> · <大会> · <作ったもの／詰まったところ>`）
- 勤務時間を [出勤記録](../../private/osakagas-worklog.md) に追記する
- このリポジトリ側で何か決めた・作った場合だけ、[ledger](../../ledger/subaru.md) に行を足す
  （対策資料そのものの進み具合は履歴side に書き、ledgerには書かない）
