# 野手分析ツールをパッケージにして後輩へ渡す

- 作成: 2026-10-09
- 状態: すばるの承認待ち
- 作業場所: `~/大阪ガス/野手分析ツール/`（このリポジトリには入れない。手順は [対策資料づくり](../private/osakagas-taisaku.md) から辿る）

## 目的

今の野手分析コード（`~/大阪ガス/分析ツール/hitter_analysis/` の5本と `run_all.py`、
`generate_ippai_matome.py`、切り抜き用の `crop_images.py`）を1つのフォルダにまとめ、
Windowsを使う後輩がzipを受け取って、手順書どおりに動かせる状態にする。

## 決まったこと

- 渡し方はzip。中に入れるのはコード・手順書・架空のサンプルデータだけで、選手データ、試合映像、過去の資料は入れない
- 後輩のパソコンはWindowsなので、Windowsで動くことを前提にする
- 範囲は野手のみ。投手は後から同じ形で足せるように、置き場所だけ空けておく

## 今のコードの問題（2026-10-09に確認）

1. ミキハウスのフォルダパスが決め打ちで残っている（`gen_reports_all.py`、`create_pptx_v3.py`）
2. ステップ3で書き出したMarkdownを、ステップ4が正規表現で読み直している。MDの書式を変えるとスライドが崩れる
3. ゾーン判定などの同じ処理が複数のファイルに書かれている
4. フォントの場所がすばるのMacに固定されている。Windowsではまず止まる
5. CSVの文字コードと見出しの揺れに弱い。WindowsのExcelで保存したCSV（Shift_JIS）や、見出しの前後に空白がないCSVで止まる
6. ファイル名が日本語のスクリプトがあり、途中で `input()` の確認待ちが入る
7. Git管理されておらず、直す前の状態に戻せない

## 作る形

```text
野手分析ツール/
  README.md              Windowsでのはじめ方（インストール→サンプルで試す→本番）
  requirements.txt
  セットアップ.bat         ダブルクリックで必要なライブラリを入れる
  実行.bat                チームフォルダをドラッグ&ドロップすると全ステップが走る
  config_template.yaml
  hitter_scouting/        本体（ファイル名はすべて英数字）
    __main__.py           python -m hitter_scouting <チームフォルダ> [--yes] [--from STEP]
    config.py             config.yamlの読み込みと必須項目のチェック
    io_csv.py             文字コードの自動判定（UTF-8/BOM/Shift_JIS）と見出しの正規化
    zones.py              ゾーン・内外角・スイング判定（ここだけに書く）
    analysis.py           打者ごとの集計結果をPythonのデータとして返す
    report_md.py          集計結果 → 選手別MD
    slides.py             集計結果 → データスライド（MDは読まない）
    stats_table.py        成績貼り付け
    images.py             画像貼り付け
    pdf.py                分析まとめPDF
    lineup_sheet.py       打線一枚まとめ
    crop.py               投球図・打球方向の切り抜き
    fonts/ipaexg.ttf      IPAexゴシックを同梱（IPAフォントライセンスで再配布可、ライセンス文も同梱）
  サンプル/架空チーム/     架空の選手名で作ったデータ一式
  tests/                  新旧の出力比較
```

## 手順

1. 今の `分析ツール/` を日付つきでバックアップし、新フォルダでGit管理を始める（`.gitignore` で CSV・画像・pptx・pdf を除外）
2. 日本新薬のデータで今のコードを流し、出力（MD・PPTXの文字・PDF）を「正解」として保存する（保存先は `~/大阪ガス` の中）
3. 共通処理を `zones.py`・`io_csv.py`・`config.py` に移す
4. `gen_reports_all.py` を「集計」と「MD書き出し」に分ける
5. `create_pptx_v3.py` を、MDではなく集計結果を直接受け取る形に書き換える
6. 残りのスクリプトを移し、`__main__.py` で一本につなぐ。`input()` は `--yes` で飛ばせるようにする
7. 日本新薬で新旧を比べ、MDとスライドの文字が一致することを確かめる（差が出たら理由を書く）
8. 架空チームのサンプルデータを作り、サンプルで全ステップが通ることを確かめる
9. Windows向けの .bat と README を書く。手元にWindowsがないため、パスの区切り文字と文字コードはコードで吸収し、Windowsでの最終確認は後輩に1回やってもらう
10. zipを作り、選手データが入っていないことを中身の一覧で確認してから渡す

## 確認すること

- 日本新薬で、新旧の出力が一致する
- 架空サンプルで、全ステップが最後まで通る
- Shift_JISのCSVと、見出しに空白がないCSVでも止まらない
- zipの中に実在の選手名・チームデータが入っていない

## 決めていないこと

- 後輩が最初に触るとき、すばるが横について見るか、READMEだけで進めてもらうか
- 投手分析を足す時期
