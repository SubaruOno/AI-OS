# 野手分析ツールをパッケージにして後輩へ渡す

- 作成: 2026-10-09（同日、v2形式を軸に書き直し）
- 状態: 実装中
- 作業場所: `~/大阪ガス/野手分析ツール/`（このリポジトリには入れない。手順は [対策資料づくり](../private/osakagas-taisaku.md) から辿る）

## 目的

今使っている「v2形式」の野手対策資料づくりを1つのフォルダにまとめ、Windowsを使う後輩が
zipを受け取って、手順書どおりに動かせる状態にする。

## 決まったこと

- 渡し方はzip。中に入れるのはコード・手順書・架空のサンプルデータだけ。選手データ、試合映像、過去の資料は入れない
- 後輩のパソコンはWindows
- 範囲は野手のみ
- 形式はv2（三菱重工East 9/3 の作り方が正本）。最初の版で旧パイプライン（create_pptx_v3 のデータページ、分析まとめPDF）を移してしまったため、作り直した
- 1枚目の右上に、初球SW率・Zn内SW率の色付きボックスを入れる（日本新薬の形）
- Zn内SW率を、ストライクゾーン内の球だけで計算するよう直す（これまでは座標のある全投球で計算していた）。配布済みの資料とは数字が変わる
- 対大阪ガスの打者別配球分析（3枚目）は、直接対戦のCSVがあるときだけ入れる
- データページは全員分つくる（打席の少ない選手を自動では外さない）

## v2形式の流れ（2026-10-09 に三菱・日本新薬・JR西日本の実物から復元）

1. 画像の切り抜き: `crop_pdf.py`（PDFと選手リストから4種類）
2. CSVのクリーニング（手作業）
3. 1枚目: 成績貼り付け → 画像貼り付け
4. 選手別MD: gen_reports_all
5. 2枚目: create_slide2_a4（A4データスライド）→ combine_v2（ボックスと差し込み）
6. （任意）3枚目: create_batter_analysis
7. reorder_final でスタメン順に組み直す
8. PowerPointで仕上げ: 表紙・作戦ページ、コメント（全体／対右／対左／警戒）、PDF書き出し
9. 別配布: 一枚まとめExcel、追加分析HTML

## 手順

1. 旧パイプライン部分（成績表・画像貼り付け・MD・一枚まとめ・切り抜き）を整理して照合する（済み。日本新薬で旧版と一致を確認）
2. v2の部品（データスライド、結合、並べ替え、対大阪ガス、追加分析）を移し、元のスクリプトの出力と照合する
3. パイプラインと config.yaml を v2 の流れにつなぎ直す
4. 架空チームのサンプルで全体を通す
5. 手順書（START_HERE.html）と README を v2 に合わせて書き直す
6. zipを作り、実名が入っていないことを確かめる。Windowsでの最終確認は後輩に1回やってもらう

- `~/大阪ガス/CLAUDE.md` のv2の手順を直すか（今は旧パイプラインの説明のまま）
